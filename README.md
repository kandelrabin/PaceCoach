## Features

- Configurable faster and slower target paces
- Digital Crown adjustment with 1-second precision
- Live running pace using HealthKit
- Stable pace coaching with Finding Pace, On Pace, Speed Up, and Slow Down guidance
- Stationary and stale-pace handling
- Apple Watch face complication for quick launch

## Tech

Swift · SwiftUI · HealthKit · WidgetKit · watchOS

## Requirements

watchOS 26.5+, Apple Watch, and Xcode for development.
